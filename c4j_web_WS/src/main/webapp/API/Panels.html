Table APP_QM_PANEL

Field NameTypeSizePrimary KeyComment
PANEL_IDLong1Auto Generated increments for each day or session.
PANEL_DATETimestampDate and time of the Panel inspection
DESCRIPTIONStringUser comments for the Panel
PLANTStringPouch 1, Pouch 2, Pouch 3, Pouch 4 for example.
STATUSString15Panel, Complete, Closed
UPDATEDTimestampSystem maintained
CREATEDTimestampSystem maintained

Transactions

GET (Read)

 Retrieve Panel for a specified panelID
 http://localhost:8080/c4j_web_WS/Panels?panelID={id} 

 Retrieve Panel records for a specific status
 http://localhost:8080/c4j_web_WS/Panels?status={status} 

 Retrieve the most recent Panels (limited to maxRows)
 http://localhost:8080/c4j_web_WS/Panels?maxRows={n} 

Status Codes

StatusMeaning
PanelIn progress Panel
CompleteCompleted Panel - not yet posted to results table
ClosedClosed Panel - results posted

JSON Example - Response

[
  {
    "panelID": 1,
    "panelDate": "2022-09-28T11:21:41",
    "plant": "Pouch 4a",
    "description": "Daily Panel",
    "status": "Panel",
    "updated": "2022-09-28T11:22:08",
    "created": "2022-09-28T11:22:05"
  }
]

POST (Create)

 Inserts data as per JSON Body
 http://localhost:8080/c4j_web_WS/Panels

*Server maintains created/updated Timestamps and panelDate - leave panelID blank as the server will auto create and return it in the response body.

JSON Example - POST

{
  "plant": "Pouch 4a",
  "description": "New Product Trial",
  "status": "Prepare"
}

JSON Example - Response

{
  "panelID": 1,
  "panelDate": "2022-09-25T08:52:30",
  "plant": "Pouch 4a",
  "description": "New Product Trial",
  "status": "Prepare",
  "created": "2022-09-25T08:52:30"
}

PUT (Update)

 Updates data as per JSON Body
 http://localhost:8080/c4j_web_WS/Panels

*Server maintains created/updated record time stamps. The Panel is matched on panelID.

JSON Example - PUT

{
  "panelID": 1,
  "panelDate": "2022-09-25T08:52:30",
  "plant": "Pouch 4a",
  "description": "New Product Trial",
  "status": "Panel"
}

JSON Example - Response

{
  "panelID": 1,
  "panelDate": "2022-09-25T08:52:30",
  "plant": "Pouch 4a",
  "description": "New Product Trial",
  "status": "Panel",
  "updated": "2022-09-25T18:55:30",
  "created": "2022-09-25T08:52:30"
}

DELETE (Delete)

 Deletes Panel as per JSON Body
 http://localhost:8080/c4j_web_WS/Panels

 Deletes Panel as per parameter for panelID
 http://localhost:8080/c4j_web_WS/Panels?panelID={id} 

*Deleting a Panel also deletes its Trays (and their Samples and Results).

JSON Example - DELETE

{
  "panelID": 1
}
