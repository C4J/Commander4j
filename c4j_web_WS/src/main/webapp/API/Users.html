Table APP_QM_USERS

Field NameTypeSizePrimary KeyComment
USER_IDString1User ID
FIRST_NAMEStringFirst name
SURNAMEStringSurname
ENABLEDStringY or N - whether the user is active

Transactions

GET (Read)

 Retrieve Users by enabled flag (Y or N)
 http://localhost:8080/c4j_web_WS/Users?enabled={Y|N} 

 Retrieve User by userID
 http://localhost:8080/c4j_web_WS/Users?userID={id} 

*If userID is supplied it takes precedence; otherwise records are filtered by the enabled flag.

JSON Example - Response

[
  {
    "userID": "DAVID",
    "firstname": "David",
    "surname": "Garratt",
    "enabled": "Y"
  }
]

POST (Create)

 Inserts data as per JSON Body
 http://localhost:8080/c4j_web_WS/Users

JSON Example - POST

{
  "userID": "MANDY",
  "firstname": "Mandy",
  "surname": "Smith",
  "enabled": "Y"
}

JSON Example - Response

{
  "userID": "MANDY",
  "firstname": "Mandy",
  "surname": "Smith",
  "enabled": "Y"
}

PUT (Update)

 Updates data as per JSON Body
 http://localhost:8080/c4j_web_WS/Users

*The User is matched on userID; firstname, surname and enabled are updated.

JSON Example - PUT

{
  "userID": "MANDY",
  "firstname": "Mandy",
  "surname": "Jones",
  "enabled": "N"
}
