Table APP_QM_PANEL_TRAY_SAMPLES

Field NameTypeSizePrimary KeyComment
TRAY_IDLong1Link to APP_QM_PANEL_TRAY
SAMPLE_IDLong2Link to APP_QM_SAMPLE
SEQUENCE_IDLongUsed to ensure that order of samples matches sequence used on physical tray. Auto generated.
UPDATEDTimestampSystem maintained
CREATEDTimestampSystem maintained

As each sample is added to a tray by scanning its barcode or manually typing its Sample ID it is added to this table. The Tray ID links the Sample ID to the tray and the Sequence ID is used for sorting so that system can maintain the same order as the physical layout. A sequenceLetter (A, B, C ...) derived from the sequenceID is also returned for display.

Transactions

GET (Read)

 Retrieve All Samples for a specific trayID
 http://localhost:8080/c4j_web_WS/TraySamples?trayID={id} 

 Retrieve record for specific trayID and sampleID primary key
 http://localhost:8080/c4j_web_WS/TraySamples?trayID={id}&sampleID={id}

POST (Create)

 Inserts data as per JSON Body
 http://localhost:8080/c4j_web_WS/TraySamples

 Create, deriving the trayID from a panelID and traySequence
 http://localhost:8080/c4j_web_WS/TraySamples?queryType=TraySequence&panelID={id}&traySequence={seq} 

*Server maintains created/updated record time stamps and always auto generates the sequenceID (any sequenceID supplied in the body is ignored). The generated value is returned in the response body.

JSON Example - POST

Specify trayID and sampleID; sequenceID is auto generated and included in the JSON response body. 
{
  "trayID": 1,
  "sampleID": 402034
}

JSON Example - Response

{
  "trayID": 1,
  "sequenceID": 5,
  "sequenceLetter": "E",
  "sampleID": 402034,
  "created": "2022-09-29T15:51:53"
}

PUT (Update)

 Updates data as per JSON Body
 http://localhost:8080/c4j_web_WS/TraySamples

*Server maintains created/updated record time stamps. The record is matched on trayID and sampleID; sequenceID is updated.

JSON Example - PUT

{
  "trayID": 2,
  "sampleID": 5,
  "sequenceID": 7
}

JSON Example - Response

{
  "trayID": 2,
  "sequenceID": 7,
  "sampleID": 5,
  "updated": "2022-09-25T18:55:30",
  "created": "2022-09-25T08:52:30"
}

DELETE (Delete)


 Deletes Sample from Tray as per parameters for trayID and sampleID
 http://localhost:8080/c4j_web_WS/TraySamples?trayID={id}&sampleID={id} 

 Deletes Sample from Tray as per JSON Body
 http://localhost:8080/c4j_web_WS/TraySamples

JSON Example - DELETE

{
  "trayID": 8,
  "sampleID": 1
}
